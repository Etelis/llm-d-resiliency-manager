# Security

Report vulnerabilities through
[GitHub's private reporting form](https://github.com/Etelis/llm-d-resiliency-manager/security/advisories/new).
Include the affected revision and a minimal reproduction without credentials or
private cluster information.

This project is experimental and has no supported release series yet. Recovery
endpoints control distributed engine state; restrict access to the manager and
the routing adapter. See [the design](docs/design.md) for current fencing limits.
