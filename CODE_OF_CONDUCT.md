# Code of conduct

We follow the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
Be respectful, discuss technical disagreements on their merits, and help keep
contribution and review welcoming.

For concerns involving this personal repository, contact
[@Etelis](https://github.com/Etelis) through the contact details on the maintainer's
profile. This repository is not yet governed by llm-d's maintainer team.
